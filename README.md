# lrpc：本地远程调用框架示例

这是一个从零实现的 TCP 调用框架，没有包装 gRPC、Thrift 或现成 RPC 框架。业务方法只看到 Go 的请求/响应类型，连接、分帧、请求 ID、超时和取消由框架管理。

## 分层

- `rpc/frame.go`：4 字节大端长度前缀分帧，并限制单帧大小。
- `rpc/envelope.go`：消息信封，包含请求 ID、方法名、错误、头部和业务负载。
- `rpc/codec.go`：负载编码接口；当前提供 JSON，后续可替换或组合压缩编码。
- `rpc/client.go`：单连接复用、等待表、取消帧、断线失败和自动重连。
- `rpc/server.go`：请求分发、连接隔离、并发上限、鉴权钩子、截止时间传播和 panic 隔离。
- `rpc/stream.go`、`rpc/client_stream.go`、`rpc/server_stream.go`：连续结果（server streaming）、按字节信用窗口的背压、分片重组和取消/断连收敛。
- `demo/` 与 `cmd/`：本机双进程演示和类型化业务定义。

## 关键语义

- 每个请求在当前连接会话内拥有独立 ID；响应只查当前会话的等待表。
- 多个请求可在同一条 TCP 连接上交错发送，响应乱序返回也不会串结果。
- `context.WithCancel` 会发送取消帧，服务端取消对应 handler 的上下文。
- `context.WithTimeout` 本地立即结束调用，并通过截止时间头部让服务端提前停止工作。
- 连接断开时，该连接上的等待调用统一返回 `ErrConnectionClosed`；后续调用自动建立新会话。
- 旧会话关闭后其等待表被清空，旧连接的迟到响应不可能匹配新调用。
- 坏帧或超大帧只关闭对应连接；非法大小、未知版本等在进入业务处理前被拒绝。
- `MaxPending` 限制等待调用数量，`WriteQueue` 限制连接写队列，`MaxHandlers` 限制服务端并发 handler。
- 鉴权通过请求头部注入，不进入业务请求结构；压缩后续可作为负载编码或内容编码层扩展。

## 连续结果与背压

- `Client.OpenStream` / `OpenStreamTyped` 发起一个返回连续片段的请求；`Stream.Recv` 按顺序返回片段，结束时返回 `io.EOF`。
- 普通调用和连续调用共享同一条 TCP 连接，用各自的请求 ID 与每会话等待表/流表独立关联；乱序、交错都不会串结果。
- 背压采用字节信用窗口：开流时客户端在 `x-lrpc-stream` 头中声明接收窗口（`StreamWindow`，默认 64KiB），服务端 `Send` 超过未确认信用即阻塞；客户端每消费一帧用 `x-lrpc-stream-ack` 归还信用。慢读取方因此直接约束发送速度，在途数据不超过约一个窗口加一个在途帧。
- 大于窗口或单帧上限的逻辑片段自动分片（`x-lrpc-stream-more`），客户端透明重组，重组期间不会死锁。
- 普通响应使用独立的优先写通道，某条流因慢读取方被流控阻塞时，同连接上的普通调用响应仍能发出，不产生队头阻塞。
- 取消（`context.Cancel` 或 `Stream.Cancel`）通过取消帧立刻通知对端；取消帧绕过普通写队列。取消或连接断开后，客户端等待结束、服务端 handler 上下文取消，信箱中无人接收的片段立即释放，不继续积压。
- 断连只结束当前会话：该会话等待表/流表清空，旧连接迟到数据不可能落入新会话；后续调用自动建立新会话。`Client.DropConnection` 可在演练中模拟真实断线。

## 运行本机演示

启动服务端：

```bash
go run ./cmd/demo-server -addr 127.0.0.1:19090 -token local-demo-token
```

另开终端运行客户端：

```bash
go run ./cmd/demo-client -addr 127.0.0.1:19090 -token local-demo-token
```

客户端会在同一条连接上完成普通调用、有序接收连续片段、制造慢读取方核对在途数据量、中途取消长流，再主动断开并自动重连。输出的是真实往返结果（片段顺序、有界在途字节数、取消/断连后的最终状态），不只是服务端监听成功。

## 测试

```bash
go test -race ./...
```

测试覆盖并发乱序响应、真实上下文取消、超时、断连结束调用、重连、旧会话响应隔离、坏帧隔离、消息大小限制和等待队列限制；流式部分覆盖片段顺序、大片段分片重组、慢读取方背压与在途字节上限、取消双向收敛、断连+重连、普通/流混合关联，以及 `TestEndToEndDrill` 全双工字节流上的完整往返演练。
